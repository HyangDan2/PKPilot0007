OPEN

파일 열기를 누르거나 화면에 파일을 끌어다 놓으면 본문과 frontmatter를 함께 불러옵니다. 문서와 이미지를 한 번에 고르면 본문의 상대경로 이미지도 함께 보입니다. 저장소에 있는 글은 기존 글 불러오기로 열고, 그대로 커밋하면 같은 경로로 덮어씁니다.

IMAGE

툴바의 이미지 버튼으로 PNG · JPEG · WebP · GIF를 올리면 설정한 원본 경로(기본 diary-src/assets/images/)와 추가 복제 경로(기본 assets/images/)에 커밋되고, 본문 커서 자리에 삽입 URL 접두사(기본 /diary/assets/images/…)로 들어갑니다. 복제 경로를 비우면 원본 한 곳에만 올립니다. 이미지를 올리려면 GitHub 토큰이 필요합니다.

COMMIT · SANITIZE

저장소에 발행은 상단 ⚙ GitHub 저장소 설정에 저장된 저장소·브랜치·글 경로로 커밋합니다. Frontmatter를 켜면 제목·카테고리·날짜·슬러그·태그·요약으로 YAML과 파일 이름을 만들고, 끄면 본문 그대로 지정 경로에 .md로 올립니다. 미리보기 HTML은 DOMPurify를 거쳐 스크립트가 실행되지 않습니다.

기본값은 HyangDan2/diary입니다. 다른 저장소·경로로 바뀌 쓸 수 있습니다.

일반 저장소는 owner/repo를 직접 입력해야 커밋할 수 있습니다.

이미지 업로드 경로 비우면 1경로만 커밋

토큰 없음 GitHub → Settings → Developer settings → Fine-grained tokens에서 대상 저장소만 고르고 권한은 Contents: Read & Write 하나면 충분합니다. 토큰은 이 브라우저(localStorage)에만 남고 커밋할 때 api.github.com으로만 나갑니다.
